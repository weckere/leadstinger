# Bitfocus Companion

`leadstinger.companionconfig` is a page for [Bitfocus Companion](https://bitfocus.io/companion)
5 with the generic OSC module 3.0 or later, 8 x 4 keys (a Stream Deck XL; on a smaller
deck, page through it or move keys):

- **Rows 1-3:** tiles 1-24 of the current set. A key shows its tile's title and, while it
  plays, a countdown; it takes the tile's colour, goes white while the tile plays and
  amber while paused. It sends `/ls/tile/N/trigger` 1 on press and 0 on release, so Hold
  to Play tiles follow the key.
- **Row 4:** GO (with the next cue's title), STOP ALL, TALK (hold to duck the beds),
  VOL − and VOL +, the title and a big countdown of what's playing, and SYNC.

1. In LeadStinger: `leadstinger-cli osc.enable --port 9000 --feedback 127.0.0.1:9001`
2. In Companion, **Import / Export ▸ Import**, choose this file and import the page. Let it
   create the connection (generic OSC, target 127.0.0.1:9000, listening on 9001) or map
   it to one of yours with the same settings.
3. Keys fill in within five seconds, or at once with **SYNC**.

Titles and countdowns use the module's value feedbacks as local variables (module 3.0,
Companion 5); keys read `null` until the first feedback arrives. Colours and the playing
state use its ordinary feedbacks. Imported here into Companion 5.0.5 with generic-osc
3.0.0: the page, the connection, every action, feedback and local variable load, and
pressing a key runs its OSC action. The file is generated by `../make-layouts.py`.
