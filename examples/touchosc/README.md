# TouchOSC

`leadstinger.tosc` is a layout for [TouchOSC](https://hexler.net/touchosc) (the current
version, 1.x) on a tablet held sideways: 16 tile buttons, each with its title and a
countdown while it plays, lit while it plays and coloured like its tile; then GO with the
next cue's title, Stop All, a hold-to-talk button, the master fader, the countdown of
what's playing, and Sync. It asks LeadStinger for everything when it starts.

1. In LeadStinger, let OSC listen on the network and send feedback to the tablet:

   ```bash
   leadstinger-cli osc.enable --port 9000 --lan true --feedback TABLET-ADDRESS:9001
   ```

   (OSC has no password, so do this on a network you trust.)
2. In TouchOSC, open `leadstinger.tosc`, then set up connection 1 as UDP: host = the
   address of the machine running LeadStinger, send port 9000, receive port 9001.
3. Play. Tile buttons send `/ls/tile/N/trigger` 1 on press and 0 on release, so Hold to
   Play tiles follow your finger.

The tile colours come from a short script on the layout's root (from `/ls/tile/N/rgb`).
This file is generated by `../make-layouts.py` in TouchOSC's file format; it hasn't
been opened in TouchOSC here, so please report anything that doesn't load.
