Collection schema

agents write with ArtifactData; {{PROTOCOL_NOTE}}
milestones/{M0..} id, order, title, status (todo · in_progress · review · blocked · done), owner, progress 0–100, depends_on [ids], summary, branch, updated
tasks/{t-…} id, milestone, title, status (todo · claimed · in_progress · blocked · review · done), owner, branch, notes, updated
decisions/{D-NNN} id, date, decision, reasoning, alternatives, decided_by, milestone
events/{ts-agent} ts (UTC ISO), agent, kind (start · claim · commit · merge · decision · blocked · finish · note), text, commit, milestone. Append only.
agents/{session-name} name, session_id, role, current_task, branch, worktree, status (active · idle · blocked · finished), last_seen (UTC ISO)
blockers/{B-NNN} id, title, detail, status (open · resolved), milestone, needs, raised_by, raised, resolved, resolution
metrics/{id} kind "tests": module, tests, branch, note, updated · kind "platform": order, platform, build, tests, runs, audio (yes · partial · untested · no · blocked), where, updated
